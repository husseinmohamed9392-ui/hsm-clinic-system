# HSM Clinic System - النسخة الأونلاين

هذه النسخة تعمل بنفس فكرة نظام الرعايات:

- الموقع الأونلاين على Vercel.
- قاعدة البيانات وتسجيل الدخول على Supabase.
- نسخة الكمبيوتر تتصل بنفس البيانات الأونلاين.
- المستخدم الأساسي هو مدير النظام.
- المدير ينشئ الطبيب والموظفين ويحدد صلاحيات كل قسم: مشاهدة، إضافة، تعديل، حذف، طباعة.
- نسخة بيانات JSON يدوية، مع سكربت اختياري لنسخ ملفات البرنامج وآخر ملف بيانات إلى Google Drive كل 12 ساعة.
- الروشتة تدعم خيارين: طباعة البيانات فقط على ورق A5 المطبوع مسبقًا، أو طباعة التصميم كاملًا باللوجو والتفاصيل وحفظه PDF.

## الربط لأول مرة

1. أنشئ مشروع Supabase مستقل للعيادة.
2. افتح SQL Editor وشغّل ملفات مجلد `supabase/migrations` بالترتيب: `001` ثم `002` ثم `003`.
3. أنشئ Edge Function باسم `create-user` من الملف `supabase/functions/create-user/index.ts`.
4. انسخ `.env.example` إلى `.env` واكتب رابط Supabase والمفتاح Publishable/Anon.
5. شغّل `Start-HSM-Clinic.bat`، ثم اختر إنشاء المستخدم الأساسي.
6. ارفع المشروع على Vercel وضع نفس متغيرات البيئة هناك.

## الصلاحيات

مدير النظام يمتلك كل الصلاحيات تلقائيًا. من شاشة **المستخدمون والصلاحيات** يمكنه:

- إنشاء طبيب أو استقبال أو محاسب أو تمريض أو مستخدم مشاهدة فقط.
- تحديد صلاحيات كل قسم بدقة.
- إيقاف المستخدم وإعادة تفعيله.

## الروشتة A5

### قائمة الأدوية والجرعات

- عند إضافة أو تعديل روشتة، ابحث باسم الدواء بالعربي أو الإنجليزي أو باسم المادة الفعالة، ثم اضغط على النتيجة لإضافتها فورًا.
- القائمة المرفقة تشمل أكثر من 25 ألف صنف متداول في السوق المصري، للاختيار والبحث فقط.
- الجرعة وطريقة الاستخدام حقل حر يكتبه الطبيب لكل دواء.
- إذا لم يظهر الدواء، اكتب اسمه واضغط **إضافة يدويًا**؛ يضاف للروشتة ويحفظ في قائمة العيادة المشتركة للاستخدام لاحقًا.
- بعد تحديث نسخة موجودة، شغّل ملف `supabase/migrations/003_medicine_catalog.sql` مرة واحدة من Supabase SQL Editor حتى يعمل حفظ الأدوية اليدوية المشترك.
- أسماء الأدوية للاقتراح وليست توصية علاجية، ويجب على الطبيب التحقق من الاسم والتركيز والشكل الدوائي قبل اعتماد الروشتة.

عند الضغط على زر الطباعة في سجل الروشتة تظهر طريقتان:

- **بيانات فقط:** يطبع اسم المريض والتاريخ والسن والأدوية وملاحظة الاستشارة فوق ورق الروشتة الجاهز، بدون إعادة طباعة اللوجو والتصميم.
- **روشتة كاملة باللوجو:** يطبع التصميم كاملًا مع اللوجو والتفاصيل والبيانات، ويمكن اختيار **Save as PDF / Microsoft Print to PDF** من نافذة الطباعة.

من **الإعدادات** يمكن تعديل حجم ولون خط الأدوية، مع إزاحة الطباعة أفقيًا ورأسيًا بالمليمتر لتصحيح اختلاف سحب الورق من طابعة لأخرى.

عند الطباعة اختر:

- حجم الورق: **A5**.
- الاتجاه: **عمودي Portrait**.
- القياس: **100% / Actual size**.
- الهوامش: **بدون هوامش None**.
- ضع الورقة المطبوعة مسبقًا في درج الطابعة بالاتجاه الصحيح.

يوجد نموذج بيانات فقط داخل `output/pdf/HSM-Prescription-A5-Print-Data-Only.pdf` لتجربة المحاذاة على ورقة واحدة.

## النسخ الاحتياطي

زر **تنزيل النسخة الآن** ينشئ ملف JSON كامل. ضع الملف في مجلد Downloads قبل تشغيل سكربت Google Drive حتى ينسخ أحدث ملف بيانات مع ملفات البرنامج.

النسخ المؤرخة لا تُحذف تلقائيًا؛ حذف النسخ القديمة يظل بقرار مدير العيادة.
